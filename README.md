# Ternopil EpiGIS

Вебінструмент для епідеміологічного картографування Тернопільської області.

## Поточний MVP

- Інтерактивна карта на Leaflet / OpenStreetMap.
- Демонстраційні записи (умовні, не реальні випадки).
- Фільтри за нозологією, територіальною громадою, датами та статусом.
- Реєстр випадків і картка вибраного запису.
- Імпорт XLSX/XLS/CSV у браузері з базовою валідацією.
- Завантаження Excel-шаблону та експорт поточної вибірки у CSV.
- Дані імпорту обробляються лише в браузері й не зберігаються на сервері.

## Локальний запуск

Потрібен Node.js 20 або сумісна актуальна LTS-версія.

```bash
npm install
npm run dev
```

Для перевірки production-збірки:

```bash
npm run build
npm run preview
```

## Розгортання на Cloudflare Pages

1. Відкрий Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Обери репозиторій `TarasB88/ternopil-epigis`.
3. Build command: `npm run build`.
4. Build output directory: `dist`.
5. Якщо Cloudflare запитує версію Node.js, задай актуальну LTS (20 або новішу, сумісну з Vite).

Після кожного push у вибрану гілку Cloudflare Pages зможе автоматично збирати нову версію.

## Формат імпорту

Обов'язкові поля: `disease`, `date`, `hromada`, `latitude`, `longitude`.

Рекомендовані поля: `id`, `settlement`, `status`, `age`, `sex`, `notes`.

Підтримуються також окремі українські заголовки: `нозологія` / `діагноз`, `дата`, `громада` / `територія`, `широта`, `довгота`, `населений пункт`, `вік`, `стать`, `примітки`.

## Важливо про конфіденційність

Ця версія є клієнтським MVP без серверної бази даних і без автентифікації. Імпортовані дані залишаються в пам'яті вкладки браузера, але карта використовує зовнішні тайли OpenStreetMap, а шрифти завантажуються з Google Fonts. Не завантажуй персональні або медично ідентифіковані дані до налаштування контролю доступу, оцінки безпеки та політик зберігання. Для робочого використання потрібно додати Cloudflare Access, захищене API та серверне сховище, а також перевірити відповідність вимогам захисту персональних даних.

## Roadmap

1. Завантаження офіційних меж громад у GeoJSON і відображення хороплетів.
2. Cloudflare Worker API, D1 та керування наборами даних.
3. Cloudflare Access і ролі користувачів.
4. Часові ряди, звіти та аналіз просторових скупчень із чітким розмежуванням сигналу й підтвердженого спалаху.
